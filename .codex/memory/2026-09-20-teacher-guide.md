## 반영한 내용

- 공개 `/help/teacher`를 4개 목차·9단계로 추가하고 교사 헤더의 `?` 도움말을 역할별 경로에 연결했다. 공용 `GuideGallery`는 `basePath`를 받아 학생·교사 이미지 경로를 재사용한다.
- `demo-video/src/teacher/`에 `TeacherGuide` 14장면·48문장과 가상 교사·학급 목업을 추가했다. 학생 안내의 접속 주소·Android Chrome·iPhone Safari 설치 목업을 재사용한다. 원고 기준은 `docs/video/teacher-guide-storyboard.md`다.
- QR 개인정산은 일반적으로 오후 8시 20분 이전 퇴근 시 일반정산, 에이스 수업 또는 오후 8시 20분 이후 근무 시 `근무`로 체크인하면 특근매식비로 정산됨을 안내한다. 자동 시간 판정으로 설명하지 않는다.
- `확인`에서 본인 체크인 기록 조회, 오류 시 관리자(영양사) 문의, 담임에게만 `학생관리`·`신청현황` 활성화, 학생관리 날짜·식사 칸의 신청 흰색/미신청 회색, 월별 체크인 현황을 설명한다.
- 화면 파손 등으로 QR 사용이 어려운 학생은 번호·이름 앞 체크박스로 선택해 `QR출력` 가능, 공고별 우리 반 신청자와 신청 시각 조회, 개인정보·선택적 얼굴등록·얼굴 체크인 확인, `?` 도움말 재열람을 포함한다.
- 사용자 요청에 따라 모든 음성 원고를 `.   `로 끝내고 1초 여유·0.5초 페이드아웃을 적용했다. 원음 말끝 검증과 전사 결과를 확인한 뒤 실측 길이로 타이밍을 갱신했다.

## 검증 상태

아래는 메인 제작 에이전트가 실제 실행 결과로 전달한 내용이다. 이 기록 담당 에이전트가 검사를 재실행한 것은 아니다.

- 제작 doctor 9/9, 앱 단위 테스트 586개·타입·변경 파일 lint, 제작 회귀 테스트 30개·타입·lint 통과.
- 48/48 원음의 마지막 20ms RMS가 -60dB 이하. 전체 전사 `CHECK=0`, `NOCHECK=0`; `특근 매식비`·`개인정산`은 재생성 후 정확한 전사 확인. 파형·전사 검증을 사람의 직접 청취 완료로 해석하지 않는다.
- 최종 MP4 전체 ffmpeg 디코딩 오류 0. `teacher-final-audio-validation.json`에서 48/48 원본문장 말끝과 최종 MP4 파형 대조 통과: 상관 0.94244~0.99996, 타이밍 오차 최대 0.0592초. 이는 파형 검사이며 직접 청취가 아니다.
- 최종 공개 페이지 헤드리스 브라우저에서 HTML5 영상 재생·170초 탐색(`readyState=4`, `error=null`), DOM 이미지 13개(본문 12장+로고) 로드, 375/768/1280px 가로 넘침 없음, 목차 `#homeroom` 이동 확인. 앞선 초안의 “본문 13장”은 로고를 포함한 DOM 이미지 수였으며 위 산출물 기준으로 정정한다.
- 실제 `HelpButton` SSR에서 `href=/help/teacher`, `target=_blank`, `rel` 및 44px 터치 영역 검증. UI 리뷰 후 좁은 간격 `gap-1`을 `gap-2`로 조정하고 헤더 줄바꿈을 허용했다.
