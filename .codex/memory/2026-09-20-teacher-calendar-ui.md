## 승인 및 변경

- 사용자 승인으로 `/teacher` 확인 탭의 석식 이력 표시를 제거하고, 상단 한 줄에 월 이동과 맨 오른쪽 주말 표시 토글을 배치했다.
- 기본 달력은 월~금 5열이며 주말 표시를 켜면 7열이다. 토요일은 파랑, 일요일은 빨강 날짜선으로 구분한다.
