# 명부 가져오기 안내

## Google Sheet 가져오기 — 학년도별 Excel로 대체됨

관리자 화면의 "Sheet연결" 버튼과 시트 URL 입력은 없어졌다. `POST /api/admin/import`는
인증 후 410을 답하고 아무것도 쓰지 않는다. 옛 경로는 학년도 명부를 거치지 않고 `User`를
직접 덮어써서, 어떤 학년도의 명부가 바뀌는지 알 수 없었다.

## 지금 쓰는 방법

사용자 관리 탭에서:

1. 학년도를 고른다(운영 중 / 준비 중 / 지난 학년도).
2. **양식 내려받기** — `기존 데이터 포함`을 켜면 현재 명부가 채워진 파일을 받는다.
   지난 학년도는 `현재 학급도 함께 표시`를 함께 고를 수 있다.
3. 파일을 고친다. 시트는 **학생**과 **교사** 두 장이다.
4. **Excel 올리기** — 반영 범위를 고른다.
   - `일부 사용자 수정`: 파일에 있는 행만 본다.
   - `전체 명부 대조`: 파일에 없는 사람도 찾아 알려 준다.
5. 미리보기에서 신규·변경·충돌 행을 확인하고 **반영 확정**을 누른다.

### 시트 열

| 시트 | 열 |
|---|---|
| 학생 | email, grade, classNum, number, name, gender |
| 교사 | email, subject, homeroom, position, name |

`gender`는 학생만 필수이며 "남" 또는 "여"로 적는다.

### 이메일은 파일로 바꾸지 않는다

이메일은 그 사람을 알아보는 열쇠라 파일이 바꾸지 못한다. 명부 표의 [이메일 변경]
다이얼로그로만 바꾸며, 바꾸면 그 사람의 로그인이 끊긴다.
